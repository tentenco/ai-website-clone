# Changelog

All notable changes to AI Website Clone Engine are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.1] - 2026-07-29

### Added

- Evidence-based comparison scorecard and prioritized optimization roadmap.

### Changed

- Renamed the project to AI Website Clone Engine across product, package,
  documentation, schema, container, release, and community surfaces.
- Replaced organization-led attribution with contributor-led project identity.

## [0.1.0] - 2026-07-29

### Added

- Evidence-driven `clone`, `adapt`, and `blend` modes.
- Clone contracts, reference ledgers, and explicit completion gates.
- Modular `inspect-site`, `audit-motion`, `clone-qa`, and `blend-references`
  skills.
- Resumable browser capture scenarios with DOM, style, state, asset, canvas,
  WebGL, media, and scroll telemetry.
- Video probing, source hashing, contact sheets, timeline adapters, and motion
  manifests.
- Pixel, geometry, timing, scroll, responsive, and reduced-motion QA gates.
- Cross-platform skill synchronization and deterministic skill tests.
- Worktree-isolated Agent Harness execution boundaries.
- Public governance, security, support, issue, pull request, and contribution
  workflows.

### Changed

- Established Node.js 24, Next.js 16, React 19, Tailwind CSS v4, and strict
  TypeScript as the independent project baseline.
- Rebuilt the project identity, documentation, metadata, and public repository
  around the evidence-driven workflow.
